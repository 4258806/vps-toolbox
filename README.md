# VPS 工具箱（vps-toolbox）

新机基线 / 日常维护用的精简工具箱，单文件 bash 脚本。
自行编写，只保留真正
用得上的部分，去掉了遥测、第三方脚本启动器和破坏性默认值。

## 一键安装

```bash
curl -fsSL https://raw.githubusercontent.com/4258806/vps-toolbox/main/install.sh | sudo bash
```

装到 `/usr/local/bin/vps-toolbox`，并建 `gjx` 快捷方式（另建 `tbox`
作兼容），装完验证通过后直接进主菜单，不用再打 `gjx`（没终端时
只打印提示）。
重新跑一遍就是更新。安装器只做下载、校验、安装两文件，
不改任何系统配置，装前会做语法检查。

## 与 vps-tune 的分工

这是两个独立项目，不是重复：

| 工具 | 负责 | 什么时候用 |
|---|---|---|
| vps-toolbox（本工具箱） | 新机基线 / 设置，给初始值 | 新 VPS 到手初始化、日常维护 |
| vps-tune | 实测调优，按实测给最终值 | 基线做完之后跑 |

**边界：调好后不要再用工具箱重写那批参数。**
具体是：跑完 vps-tune 后，不要再点“4 BBR 管理”和“6 → 14 内核参数优化”，
否则会把 vps-tune 按实测给的最终值重写回固定预设。

## 隐私：零遥测

本脚本**不收集、不发送任何信息**：没有使用统计上报，没有 IP 查询，
没有地理位置 / 运营商查询（系统信息里只显示本机 IP 和 DNS）。

例外只有三处用户批准的第三方脚本，执行前都会先打印警告并要确认：

| 功能 | 第三方脚本 | 用途 |
|---|---|---|
| 5 WARP 管理 | fscarmen 的 warp 脚本（GitLab） | 接 Cloudflare WARP 出站 |
| 5 一键重装系统 | leitbogioro / bin456789 的重装脚本（GitHub） | 仅空机器换系统 |
| 12 切换系统更新源 | linuxmirrors 脚本 | 只有默认源慢 / 坏时才切 |

除此之外，本脚本不下载、不执行任何远程脚本。

## 适用系统

仅 Debian / Ubuntu，其他发行版会明确拒绝。
XanMod 内核安装（10 项）仅支持 x86_64；ARM64 机器会直接拒绝并说明原因，
不会走第三方脚本。

## 安装

```bash
# 传到 VPS（以 /root 为例），加执行权限
chmod +x vps-toolbox.sh

# 直接运行
./vps-toolbox.sh

# 创建快捷键（首次运行后：系统工具 → 1 设置脚本启动快捷键，默认名 gjx）
# 之后直接输入 gjx 即可打开
gjx
```

需要 root 权限运行（系统信息查询和帮助除外）。

## 用法

交互菜单直接运行；也可以带子命令：

```bash
gjx info                    # 系统信息查询
gjx update                  # 系统更新
gjx clean                   # 系统清理
gjx bbr                     # BBR 管理（基线开启）
gjx warp                    # WARP 管理
gjx settings                # 系统工具子菜单
gjx help                    # 显示帮助
gjx version                 # 显示版本号
gjx self-update             # 更新工具箱到最新版
```

## 新机初始化建议顺序

```
4（DNS 国内）→ 6（IPv4 优先）→ 8（swap 2048M）
→ 9（上海时区）→ 11（主机名）→ 10（XanMod BBRv3，仅 x86 新机）
→ 14（基线预设，仅跑 vps-tune 之前）
→ 再跑 vps-tune 实测调优，调好后不再动 14 和 4
```

## 各功能说明

- **1 系统信息查询**：纯只读。主机名、系统版本、内核、CPU、内存、磁盘、
  流量累计、拥塞算法、本机 IP、DNS、运行时长。没有遥测，没有 IP 查询。
- **2 系统更新**：apt update + full-upgrade。执行前会确认并提示“会装新
  内核、可能改变默认启动内核（XanMod 用户注意）”；装完对照内核清单，
  提示是否需要重启和用 `uname -r` 核对。不 `pkill -9` 杀 apt。
- **3 系统清理**：apt autoremove / clean + journal 清理
  （保留最近 7 天，总量不超过 500M）。不用 `--vacuum-time=1s`（等于全清日志）。
- **4 BBR 管理**：只写两个基线参数（fq + bbr）到
  `/etc/sysctl.d/99-vps-toolbox-bbr.conf` 并生效。BBRv3 需要 XanMod
  内核，见 10 项。本项不下载执行第三方脚本。
- **5 WARP 管理**：下载执行 fscarmen 的 warp 脚本。执行前会警告三件事：
  会改 DNS（用完改回国内 DNS）、会改出口 IP（别在主力 / 代理节点常驻）、
  `warp b` 里藏着 DD 别误点。
- **99 卸载**：清 crontab 相关行、删快捷键、删脚本本身，不动系统配置。
- **100 更新工具箱**：重新下载 install.sh 并执行，等同于手动跑一键
  安装命令；装完直接进新版主菜单，不回旧菜单。更新前会确认。
- **6-3 改 SSH 端口**：改前警告会断开当前会话、Komari / 1Panel / 面板
  的连接记录要同步改；改后 `sshd -t` 校验并确认新端口在监听；
  不删 `sshd_config.d`，不卸载防火墙软件。
- **6-4 DNS**：国外 / 国内 / 手动三档；国内是 223.5.5.5 / 183.60.83.19
  + v6 2400:3200::1 / 2400:da00::6666。写完 `chattr +i` 加锁，
  再改要先解锁。
- **6-5 一键重装**：只限空机器，须输入确认口令“重装系统”才执行。
  Linux（Debian 13/12/11、Ubuntu 24.04/22.04）走 bin456789，
  Windows（11/10）走 leitbogioro。默认密码是公开的，装完立刻改。
  甲骨文机器重装请走控制台，不要用 DD。
- **6-6 IPv4 优先**：往 `/etc/gai.conf` 写 `precedence ::ffff:0:0/96 100`。
- **6-8 swap**：默认 2048M，可选 1024M / 4096M / 自定义。重建前会确认；
  只改大小，不改 swappiness（基线 swappiness=10 请用 14 项的预设）。
- **6-10 BBRv3**：x86_64 装 XanMod 内核（按 CPU 指令集选包），装完提示重启
  并用 `uname -r` 核对。根分区需 3GB 可用空间，无 swap 时自动建 1GB。
  ARM64 直接拒绝。
- **6-12 换源**：下载 linuxmirrors 脚本到临时文件，打印大小与 SHA-256，
  确认后再执行，固定 `--backup true` 备份原配置。
- **6-13 fail2ban**：装 fail2ban + rsyslog；默认 bantime=10m、
  findtime=10m、maxretry=5（写 `/etc/fail2ban/jail.d/sshd.local`）；
  默认开启 recidive 监狱：1 天内被封 5 次 → 封 1 周。
  卸载只停服务、删包，**不删 `/etc/fail2ban` 配置**。
- **6-14 内核参数优化**：5 个固定预设（高性能 / 均衡 / 网站 / 直播 /
  游戏服）+ 还原默认。文件头和菜单都写明了分工边界：
  只在跑 vps-tune 之前用，调好后绝不要再点。没有远程自动调优。
- **6-15 日志**：journalctl 查看 + 安全清理（保留 7 天 / 3 天 / 500M）。
- **6-16 环境变量**：查看已生效变量与配置文件里的变量，可编辑、重载。
- **6-17 重启**：Y/N 确认后重启。

## 安全规则

- 破坏性操作（重装、改 SSH 端口、重建 swap、装内核、重启、卸载）
  一律要 Y/N 确认；重装还要额外输入确认口令。
- `set -u`，变量加引号，不用 `eval`，不以管道方式执行远程脚本。
- 第三方脚本先下载到临时文件、确认非空再执行，执行后删除临时文件。
- XanMod 密钥只从官方 `dl.xanmod.org` 拉，失败就报错退出，不回退到
  其他来源；密钥本身是 TOFU（下载即信任），与 XanMod 官方安装
  说明一致，尚未做指纹比对。

## 已知限制

- XanMod 官方已停对 Ubuntu 22.04（jammy）及更老系统的 APT 支持，
  这些系统上 10 项会直接拒绝，请升级到 Debian 12 / Ubuntu 24+。
- `check_disk_space` 只查 `/` 可用空间，不单独查 `/boot`；`/boot`
  独立分区很小的机器装内核前请自行确认空间。
- 系统信息里的总接收 / 总发送只统计 eth / ens / enp / eno 开头的网卡，
  是自开机累计值，不是速率。
- WARP、DD、换源三个功能依赖第三方脚本本身的质量，本脚本只负责
  下载、警告和确认，不审计它们的内容。
